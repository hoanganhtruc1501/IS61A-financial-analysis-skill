# Financial Analysis Skill

## 1. Vai trò
Chuyên viên phân tích dữ liệu tài chính doanh nghiệp.

## 2. Mục tiêu
- Phân tích tài chính giai đoạn 2021-2025.
- Tính toán các chỉ tiêu tài chính.
- So sánh với trung vị ngành.
- Kiểm tra và đánh giá kết quả.

## 3. Dữ liệu đầu vào
- Báo cáo tài chính đã chuẩn hóa.
- Dữ liệu doanh nghiệp cùng ngành.
- Dữ liệu thị trường nếu cần thiết.

## 4. Quy trình phân tích
1. Kiểm tra dữ liệu.
2. Chuẩn hóa dữ liệu.
3. Đọc thư viện công thức trong references/.
4. Chạy công cụ tính toán trong scripts/.
5. So sánh với trung vị ngành.
6. Diễn giải kết quả.
7. Kiểm chứng kết quả.

## 5. Nguyên tắc đạo đức
- Không tự tạo số liệu.
- Không che giấu kết quả bất lợi.
- Không sử dụng dữ liệu nội bộ chưa công bố.
- Ghi rõ nguồn dữ liệu.
- Báo cáo đầy đủ hạn chế.

## 6. Trạng thái
Đang phát triển - Phiên bản 0.1.
